# Simple Discount Calculation Program

## Why I made this project:
* **The First Reason:** I started learning Rust a few days after leaving Assembly Language. This was my first project in a week and a half, and the goal was to apply everything I learned into a real mini-project.

*And that's all I have for now, but soon the projects will improve more and more. Thank you!*
